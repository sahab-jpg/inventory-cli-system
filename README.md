# Local Inventory & Billing System

A command-line interface (CLI) software built in **C++** designed to help small local businesses manage inventory, track stock levels in real-time, and handle basic billing calculations without relying on clunky, bloated software.

## Features
* **Product Management:** Add new items with unique IDs, pricing, and stock quantities.
* **Instant Lookup:** Search inventory instantly by product name.
* **Smart Billing Counter:** Calculate total order costs, automatically deducts purchased quantities from live stock, and checks against out-of-stock errors.
* **Memory Efficient:** Built using standard template libraries (`std::vector`) for clean structure and fast execution.

## Tech Stack
* Language: C++
